## 2. Раскладка эксперимента

```
experiments/<имя>/          в репозитории
  hypothesis.md             карточка (коммит до первого запроса к данным)
  artifacts/                артефакты стадий — их замораживает journal.py
  sql/                      каждый запрос к источнику
  scripts/                  скрипты эксперимента (обычно — вызовы templates/)
  reports/<дата>.md         утренние отчёты
journal.jsonl               общий для всех экспериментов (поле experiment)
~/<имя>-work/               вне репозитория: data, vec, train, logs, venv
```

## 4. Что guard останавливает и что нет

Отказ (считает и не пропускает): вердикт рукой; `trials` рукой; α вместо
вычисленной; порог на нуле; неконсервативный конец интервала; перевёрнутое
направление; несходящиеся размерности; невыводимая выведенная константа;
назначенная константа без basis; измеренная константа в правиле; кандидат вне
`selection.space`; не та роль ящика; второе вскрытие подтверждающего; не тот
оценщик (хеш); набор values не тот; правка журнала в обход; потолок риска,
выданный за выведенный.

Не останавливает — работа ревизии и тормоза агента: не та величина под верным
именем; неуместная модель зависимости; неверный нуль; работа в обход guard
(посчитать вне журнала и решить потом). Оси перебора вне `space` guard не видит;
`selection.objective` — только «argmax|argmin величины», условия живут прозой.
