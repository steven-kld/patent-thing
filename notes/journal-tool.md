# `tools/journal.py`: контракт

Инструмент записи в `journal.jsonl`. Нормативная рамка — `notes/stages-v2.md`
§10; обоснование схемы Protocol — `notes/protocol-schema.md`. Здесь только
контракт: команды, payload, форматы артефактов.

```
journal.py freeze   < payload.json     заморозка артефакта стадии
journal.py open     < payload.json     вскрытие ящика
journal.py close    < payload.json     закрытие ветки, источника, стадии
journal.py diverge  < payload.json     расхождение с обещанным
journal.py verify                      состояние, следующий шаг, нарушения
journal.py next-id
```

Отказ (`ОТКАЗ: …`, exit 1) — результат работы, а не сбой. Скрипт коммитит
каждую запись сам: один коммит на запись, артефакт в том же коммите (J5).

---

## 1. Что скрипт ставит сам и из входа не принимает

```
id  ts  type  sha256  prev  role  trials  verdict
```

Переданные снаружи — отказ (J4). Причина у каждого своя и одна общая: это
поля, которые нельзя назначить, не зная ответа. `role` объявлена в Lockbox до
первого вскрытия, `verdict` выводится правилом, `trials` вычисляется из
объявленного множества сравнений, `prev` — хеш предыдущей стадии.

## 2. Общие поля payload

| | |
|---|---|
| `stage` | одна из `Proposal Manifest Universe Lockbox Protocol Build Tearsheet Incubation Registry`. У заморозки — чей артефакт, у остальных — где случилось |
| `claim` | словами автора, дословно. Не меньше четырёх слов: нужно утверждение, а не тема. У разведочного вскрытия запрещён — его генерирует скрипт (J3) |
| `experiment` | id заморозки Proposal. Пуст только у самой заморозки Proposal |
| `refs` | список целых id существующих записей. Обязателен у расхождения |

## 3. `freeze`

```json
{"stage": "Manifest", "experiment": 6, "claim": "…", "artifact": {"path": "artifacts/manifest.json"}}
```

`artifact` — объект с единственным полем `path`; файл обязан существовать и
лежать внутри репозитория. `sha256` и `prev` считает скрипт.

Отказ, если: у стадии уже есть действующая заморозка (U2); предыдущая стадия не
заморожена и не объявлена недоступной записью `close` (S2); стадия была обнулена
и восстанавливается тем же `sha256` без `refs` на убившее её расхождение (S4).

У стадии `Protocol` артефакт обязан быть `.json` и проходит проверку по схеме —
на заморозке печатаются α, бюджет подтверждений, мощность и ожидаемые ключи
`values`.

## 4. `open`

```json
{"stage": "Build", "experiment": 6,
 "lockbox": {"freeze": "<sha256 заморозки Lockbox>", "box": "scout_2019"},
 "values": {"pnl_excess.point": 1840.0}}
```

Роль читается из артефакта Lockbox. Дальше два разных события:

**разведка** — `claim` генерирует скрипт, `verdict` и `trials` пусты, `values`
свободны, `artifact` необязателен. Вскрытий не ограничено (E4), в статистику не
входят (C3).

**подтверждение** — `claim` обязателен, `artifact` обязателен, набор ключей
`values` обязан **точно** совпасть с объявленным в Protocol. Вердикт вычисляет
скрипт. Отказ, если ящик уже вскрыт (E7, C2), если нет действующего Protocol,
если `trials ≠ 1`, если бюджет подтверждений исчерпан. В запись попадают также
`alpha`, `family_risk` и `protocol_sha256`.

## 5. `close` и `diverge`

```json
{"stage": "Incubation", "experiment": 6, "claim": "источник статичен, стадия недоступна"}
{"stage": "Universe", "experiment": 6, "refs": [9], "claim": "…", "invalidates": ["Universe"]}
```

`invalidates` — список стадий, чьи артефакты перестали действовать; пустой
список, если расхождение правит только текст. Каскад на старшие стадии считает
скрипт (S3), перечислять их не нужно.

## 6. Артефакт Lockbox: минимальный машиночитаемый контракт

Полная схема Lockbox — отдельная работа. Но роль ящика читается, а не
принимается (J4, E1), поэтому артефакт обязан быть JSON хотя бы с этим:

```json
{
  "boxes": {
    "scout_2019":   {"role": "разведка"},
    "confirm_2020": {"role": "подтверждение"}
  },
  "independence": {"scout_vs_confirm": 0.81}
}
```

`independence` нужен только если Protocol объявляет `combine: independent` или
`aggregate` по нескольким ящикам: необъявленная независимость считается
отсутствующей (E13).

## 7. Артефакт Protocol: формат

JSON. Поля и их обоснование — `notes/protocol-schema.md` §1. Скелет:

```json
{
  "quantities": {
    "pnl_excess": {
      "unit": "USD",
      "population": "verdict_box",
      "better": "higher",
      "range": [-120000, 150000],
      "estimator": {"spec": "что считает", "path": "tools/est_pnl.py", "sha256": "…"},
      "uncertainty": {"method": "paired_bootstrap",
                      "dependence": {"block": 1, "unit": "row"},
                      "level": 0.95, "iterations": 1000, "seed": 42},
      "null": {"value": 0, "kind": "mathematical",
               "dispersion": {"sd": {"const": "c_sd_null"}}}
    }
  },
  "constants": [
    {"name": "c_hour", "value": 50, "unit": "USD/hour",
     "provenance": "назначено", "basis": "кто и на каком основании назначил"},
    {"name": "c_payback", "value": 3000, "unit": "USD",
     "provenance": "выведено", "derivation": "2 * c_hour * c_hours_per_day * c_days"},
    {"name": "c_sd_null", "value": 700, "unit": "USD",
     "provenance": "измерено", "source": {"entry": 11, "artifact_sha256": "…"}},
    {"name": "c_family_risk", "value": 0.05, "unit": "1",
     "provenance": "назначено", "basis": "потолок семейного риска, назначен автором"}
  ],
  "verdict_candidates": ["b2"],
  "slices": [{"id": "q1", "definition": "первый квартал", "bears_verdict": false}],
  "verdict_box": [{"lockbox_sha256": "…", "box": "confirm_2020"}],
  "decision_rule": {"all": [
    {"left": {"quantity": "pnl_excess", "take": "ci_low"},
     "op": ">=", "right": {"const": "c_payback"}}]},
  "selection": {"box": {"lockbox_sha256": "…", "box": "scout_2019"},
                "objective": "argmax pnl_excess",
                "space": {"model": ["b1", "b2"], "C": [0.1, 1, 10]}},
  "multiplicity": {"dependence": "unknown", "combine": "union_bound",
                   "ceiling": {"const": "c_family_risk"}}
}
```

Что считается, а не объявляется: α, бюджет подтверждений, `trials`, вердикт,
мощность, доля принимаемого диапазона, размерности выведенных констант.

Что обязательно при многих ящиках: `aggregate` с `expr` и
`independence: {lockbox_key: …}`.

Язык выражений — имена, числа и `+ − * / **`. Ни вызовов, ни условий, ни
дизъюнкции: `или` — это то, что считает `trials` (P2).

## 8. Записи прошлой схемы

Пять первых записей журнала сделаны прошлой схемой (`event: register/result`).
Журнал не редактируется, поэтому скрипт их **терпит**: читает для нумерации и
проверки дописывания, не валидирует, в счётчики нового дизайна не берёт и
помечает в `verify`. Новый эксперимент начинается заморозкой `Proposal`.

## 9. Порядок работы с нуля

```
journal.py verify                 скажет: эксперимента нет, следующий шаг Proposal
```

Дальше по одной заморозке на стадию, в порядке `STAGES`. Перед каждой — артефакт
на диске; `verify` после каждой скажет, какая стадия следующая.

Где это становится небезразлично к порядку:

```
Lockbox    ящики и роли объявлены здесь, до первого вскрытия. Дальше их нет
Protocol   абсолютные числа — только теперь. На заморозке печатаются α,
           бюджет и мощность: это и есть ответ на «на что рассчитан протокол»
Build      разведочные вскрытия — сколько нужно, каждое записью
Tearsheet  одно подтверждающее вскрытие. Вердикт вычислит скрипт
```

## 10. Чего инструмент не проверяет

Названо в `notes/protocol-schema.md` §7.2: неуместная модель зависимости в
`uncertainty`, неверно выбранный нуль, не та величина под верным именем. Все три
проходят каждую проверку и остаются предметом ревизии шагов 26 и 36 — из
контекста, не видевшего работы, по списку вопросов, объявленному до неё (V5–V7).
