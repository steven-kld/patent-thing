## Тай-брейкер

`01`, `02`, `03`, `07` запускались **до** принятия тай-брейкера и содержат
недетерминированный `ROW_NUMBER() OVER (PARTITION BY app_id ORDER BY mail_dt)`.
При перезапуске добавлять `, ifw_number`. Остальные уже с ним.

## `TABLESAMPLE`

`04`, `05`, `07`, `11`, `12` используют `TABLESAMPLE SYSTEM` — воспроизводятся
**по частотам, но не построчно**. Одни и те же строки повторно не получить.

Отсюда же: `maximum_bytes_billed` проверяется по **нескану**, а не по выборке.
Запрос, у которого сумма полных столбцов больше 200 ГиБ, отклоняется при любой
доле выборки. Так был отклонён `bodyText + section103RejectionText`
(249,23 ГиБ), и потому `sections.section103RejectionText` проверить не удалось.

## Как запускать

Файлы начинаются с комментария `--`, и `bq` принимает его за флаг командной
строки. Запускать через перевод строки:

```bash
q=$(printf '\n%s' "$(cat 09_parent_vs_pair.sql)")
bq query --use_legacy_sql=false --maximum_bytes_billed=214748364800 "$q"
```
