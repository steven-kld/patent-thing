# Запросы стадий 1-2, проход v2 (2026-09-11/12)

Каждое число в замороженных `artifacts/proposal.md` и `artifacts/manifest.md`
должно прослеживаться до запроса в этой папке — этого требует A4. Ниже —
соответствие.

Папка описывает **второй** проход. Файлы прошлого прогона лежат уровнем выше
(`notes/sql/01_…12_`) и к этому эксперименту отношения не имеют.

## Общее

Задания создаются в **своём** проекте и читают из публичного
`patents-public-data`. Запуск с `--project_id=<публичный>` даёт
`bigquery.jobs.create permission denied` — это не про биллинг, а про то,
в чьём проекте создаётся задание.

Каждый запрос запускался с явным `--maximum_bytes_billed`, как требует
`.claude/CLAUDE.md`. Предохранитель сработал один раз по делу: лимит
10 000 000 на `INFORMATION_SCHEMA` упал с «10485760 or higher required» —
запрос не выполнился и не тарифицировался.

Суммарно за две сессии: около 45 ГиБ ≈ $0,27.

## Чего здесь нет намеренно

**Поокошных и покластерных долей исходов.** Они не измерялись ни разу, и это
не упущение: именно их отсутствие делает выбор подтверждающего ящика слепым.
Адрес ящика (2016-07 … 2016-12) назван на стадии 2, до любого такого замера.
Свойство сохраняется до шага 16 и разрушается одним запросом.

Измерена только пулированная базовая ставка §103 = 72,9% на популяции после
критериев 1-3 — она не говорит, какое окно выгоднее.

## Грабли инструмента, стоившие времени

```
--max_rows ставится ПОСЛЕ подкоманды query.  До неё bq падает с
                                             'Unknown command line flag'
по умолчанию bq отдаёт 100 строк             усечение молчаливое; десять
                                             датасетов пришлось дозапрашивать
кириллица в псевдонимах столбцов             BigQuery отказывает
'rows' — зарезервированное слово             как псевдоним не годится
LIMIT не уменьшает скан                      платят за столбец целиком
WHERE не уменьшает скан                      и добавляет свой столбец:
                                             577 МБ -> 1 259 МБ
INFORMATION_SCHEMA тарифицируется            минимум 10 МиБ на запрос
```
